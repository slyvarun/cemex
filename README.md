# 🏗️ Cemex Infra - Ready Mix Concrete Solutions

**Cemex Infra** is a professional and responsive website designed to showcase **ready-mix concrete solutions** for construction projects.
This freelancing project enhances Cemex Infra's online presence, providing an easy way for clients to explore services and products.

## 🌟 Features
- 🏢 **Company Overview** - Learn about Cemex Infra and its expertise in construction.
- 📋 **Services Section** - Displays different grades of ready-mix concrete.
- 🏗️ **Projects Showcase** - Highlights completed projects.
- 📩 **Procurement Form** - Clients can send purchase inquiries.
- 📱 **Fully Responsive** - Works seamlessly on mobile, tablet, and desktop.
- ⚡ **Optimized Performance** - Fast load times with clean and structured code.
